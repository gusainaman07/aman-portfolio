# Personal portfolio

This is a dependency-free, responsive portfolio website. Open `index.html` directly in a browser to preview it.

## Personalize it

1. Replace the placeholder email in `index.html`.
2. Update the About, Skills, and project copy with your final information.
3. Add your LinkedIn URL and any other social links.
4. Add more project cards by copying a `.mini-project` block.
5. Replace the Google Fonts links if the site needs to work without an internet connection.

## Publish it

The `portfolio` folder can be deployed as a static site on GitHub Pages, Netlify, or Vercel. For GitHub Pages, select the repository branch and `/portfolio` folder in the Pages settings if the repository setup supports folder publishing.

# Aman Singh Portfolio

A dependency-free, responsive portfolio for Aman Singh, a Computer Science graduate pursuing fresher opportunities in software engineering and data analytics.

Live portfolio: [gusainaman07.github.io/aman-portfolio](https://gusainaman07.github.io/aman-portfolio/)

## Features

- Technical, project-first portfolio layout
- Software engineering and data analyst profile positioning
- Separate role-specific resumes with view and download actions
- Project, achievement, hackathon, startup, certificate, and skills sections
- Click-to-play looping background music
- Pixel-art `duel.gif` scene near the footer
- Responsive desktop and mobile layout

## Run locally

Open `index.html` directly in a browser. No build step or package installation is required.

Keep these asset paths intact when moving or deploying the site:

- `my_resume's/aman-main.pdf` - software engineering resume
- `my_resume's/Aman_Singh_Resume (5) (3).pdf` - data analyst resume
- `background-music/portfolio-music.mp3` - background music
- `gif-image/duel.gif` - footer animation

## Personalize it

1. Update the profile, project, and contact details in `index.html`.
2. Replace the LinkedIn and GitHub URLs if needed.
3. Replace the resume files while keeping the links in the resume section current.
4. Replace the music file or GIF only with assets you own or are licensed to use.
5. Update the Google Fonts links if the site needs to work without an internet connection.

## Publish it

This is a static site and can be deployed directly to GitHub Pages, Netlify, or Vercel. Upload the project root so `index.html` and all asset folders remain at the same relative paths.
